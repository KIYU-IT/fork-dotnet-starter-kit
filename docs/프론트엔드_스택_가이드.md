## Blazor 개요

### Blazor WebAssembly란?

**Blazor WebAssembly**는 C#으로 작성하는 Single Page Application (SPA) 프레임워크입니다.

**핵심 특징**:
- **C# 언어**: JavaScript 대신 C#으로 프론트엔드 개발
- **WebAssembly**: 브라우저에서 .NET 런타임 실행
- **풀스택 C#**: 백엔드와 프론트엔드 동일 언어 사용
- **타입 안정성**: 컴파일 타임 타입 체크
- **Razor 문법**: HTML + C# 혼합 문법

### React/Angular와의 차이

| 특징 | Blazor | React | Angular |
|------|--------|-------|---------|
| **언어** | C# | JavaScript/TypeScript | TypeScript |
| **실행 환경** | WebAssembly | Browser JS | Browser JS |
| **컴파일** | AOT 컴파일 | Transpile | AOT 컴파일 |
| **타입 시스템** | 강타입 (C#) | 약타입/TypeScript | 강타입 (TypeScript) |
| **템플릿 문법** | Razor (@if, @foreach) | JSX | Template syntax |
| **상태 관리** | 서비스/이벤트 | useState/Redux | Services/RxJS |
| **라우팅** | @page directive | React Router | Angular Router |
| **의존성 주입** | 내장 DI | Context/Props | 내장 DI |
| **생태계** | 작음 | 매우 큼 | 큼 |

    private List<ProductDto>? products;

    // React useEffect와 유사
    protected override async Task OnInitializedAsync()
    {
        await LoadProducts();
    }

    private async Task LoadProducts()
    {
        products = await ProductsClient.GetAllAsync();
    }

    private async Task CreateProduct()
    {
        var dialog = await DialogService.ShowAsync<CreateProductDialog>("새 제품");
        var result = await dialog.Result;

        if (!result.Canceled)
        {
            await LoadProducts();
            Snackbar.Add("제품이 생성되었습니다", Severity.Success);
        }
    }

    private async Task EditProduct(Guid id)
    {
        var parameters = new DialogParameters { ["ProductId"] = id };
        var dialog = await DialogService.ShowAsync<EditProductDialog>("제품 수정", parameters);
        var result = await dialog.Result;

        if (!result.Canceled)
        {
            await LoadProducts();
            Snackbar.Add("제품이 수정되었습니다", Severity.Success);
        }
    }

    private async Task DeleteProduct(Guid id)
    {
        var confirmed = await DialogService.ShowMessageBox(
            "확인",
            "정말 삭제하시겠습니까?",
            yesText: "삭제", cancelText: "취소");

        if (confirmed == true)
        {
            await ProductsClient.DeleteAsync(id);
            await LoadProducts();
            Snackbar.Add("제품이 삭제되었습니다", Severity.Success);
        }
    }
}

// AppState.cs (Redux Store와 유사)
public class AppState
{
    // 상태
    private string? _userName;
    private string? _theme = "light";
    private int _notificationCount = 0;

    // 이벤트 (상태 변경 알림)
    public event Action? OnChange;

    // Getter/Setter
    public string? UserName
    {
        get => _userName;
        set
        {
            _userName = value;
            NotifyStateChanged();
        }
    }

    public string Theme
    {
        get => _theme ?? "light";
        set
        {
            _theme = value;
            NotifyStateChanged();
        }
    }

    public int NotificationCount
    {
        get => _notificationCount;
        set
        {
            _notificationCount = value;
            NotifyStateChanged();
        }
    }

    // Actions (Redux actions와 유사)
    public void SetUser(string userName)
    {
        UserName = userName;
    }

    public void ToggleTheme()
    {
        Theme = Theme == "light" ? "dark" : "light";
    }

    public void IncrementNotifications()
    {
        NotificationCount++;
    }

    private void NotifyStateChanged() => OnChange?.Invoke();
}

// Program.cs에서 등록 (Redux store 등록과 유사)
builder.Services.AddScoped<AppState>();

## 인증/인가

### JWT 인증 구현

```csharp
// infrastructure/Auth/JwtAuthenticationService.cs
public class JwtAuthenticationService : IAuthenticationService
{
    private readonly HttpClient _httpClient;
    private readonly AuthenticationStateProvider _authStateProvider;

    public async Task<bool> LoginAsync(string email, string password)
    {
        var request = new TokenGenerationCommand(email, password);
        var response = await _httpClient.PostAsJsonAsync("/api/v1/tokens", request);

        if (response.IsSuccessStatusCode)
        {
            var tokenResponse = await response.Content.ReadFromJsonAsync<TokenResponse>();

            // 토큰 저장 (localStorage)
            await _localStorage.SetItemAsync("authToken", tokenResponse.Token);
            await _localStorage.SetItemAsync("refreshToken", tokenResponse.RefreshToken);

            // 인증 상태 업데이트
            ((JwtAuthenticationStateProvider)_authStateProvider).NotifyUserAuthentication(tokenResponse.Token);

            return true;
        }

        return false;
    }

    public async Task LogoutAsync()
    {
        await _localStorage.RemoveItemAsync("authToken");
        await _localStorage.RemoveItemAsync("refreshToken");

        ((JwtAuthenticationStateProvider)_authStateProvider).NotifyUserLogout();
    }
}
```
